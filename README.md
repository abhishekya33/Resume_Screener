# 🤖 AI-Powered Resume Screener

An intelligent resume screening system that uses **BERT-based NLP** to automatically rank candidates against job descriptions.

## ✨ Features

- 📄 Upload resumes (PDF/DOCX files)
- 🧠 Semantic similarity using BERT embeddings
- 🔍 Keyword matching for technical skills
- 📊 Ranked candidate dashboard with scores
- ⚡ Real-time analysis and feedback

## 🏗️ Tech Stack

| Layer | Technology |
|-------|------------|
| **Backend** | FastAPI, Python, BERT, PyTorch |
| **Frontend** | React, Vite, Axios |
| **ML Models** | Sentence-BERT, scikit-learn |
| **PDF Parsing** | PyPDF2, python-docx |
